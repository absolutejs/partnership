## 0.3.0 — 2026-10-25

### Added

- **Construct assets from immutable source references with provenance, content integrity validation, and deterministic evidence-bound scenario calculations. Render proposed actions and questions separately from quoted source information.** (`buildAssetEvidence`, `renderAssetEvidencePlan`, `validateAssetEvidenceDocument`, `calculateAssetScenario`, `AssetEvidencePlanSchema`, `ASSET_EVIDENCE_HEADINGS`, `AssetEvidenceSource`, `AssetEvidenceRecord`, `AssetEvidencePlan`, `AssetEvidenceDocument`)

### Changed

- **Drafting and editing return a source-backed construction record; factual blocks are selected by evidence ID and rendered by code rather than freely authored by the model. Existing prose is editing context, not evidence. Hosts must independently review proposal and question blocks for factual presuppositions.** (`draftPartnershipAsset`, `editPartnershipAsset`, `PartnershipAsset`, `AssetSource`)

## 0.1.0 — 2026-09-24

### Breaking
